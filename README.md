# «Красная икра» — сайт ресторана

Адаптивный одностраничный концепт сайта ресторана в Магадане: тёмно-зелёная и золотая палитра, меню, галерея, контакты и демонстрационная форма бронирования.

## Как посмотреть
Откройте `index.html` в браузере или включите GitHub Pages в настройках репозитория.

## Важно перед публикацией
- Форма бронирования демонстрационная: данные никуда не отправляются.
- Фотографии — временные стоковые референсы, не фотографии ресторана.
- Адрес, телефон, часы работы, меню и цены необходимо подтвердить у ресторана.
- Для настоящих бронирований подключите форму к почте, CRM или сервису бронирования.
- Добавьте политику конфиденциальности и согласие на обработку данных, если будете собирать персональные данные.

## GitHub Pages
1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/(root)`, нажмите **Save**.
4. После публикации сайт обычно доступен по адресу:
   https://vladimir23062006-web.github.io/test-krasnaya-ikra/

«Вкус Охотского моря. Панорамный Магадан». Севиче из гребешка, карпаччо из оленины и морские деликатесы представлены как концептуальные позиции, которые нужно сверить с актуальным меню.
